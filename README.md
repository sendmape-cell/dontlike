# MAPEMORRIS — магазин и студия продюсера

Next.js 16, TypeScript, Tailwind CSS 4, Lucide. Рабочий каталог, HTML5 Audio, корзина, серверное сохранение битов, защищённая админка и оплата через PayPal-инвойсы с ручным подтверждением.

## Запуск

Нужны Node.js 22.13+ (рекомендуется 24) и npm.

```powershell
cd "C:\Users\mapemorris\Documents\Codex\2026-10-04\files-pasted-by-the-user-mapemo\outputs\mapemorris"
npm install
npm run admin:setup
npm run dev
```

Магазин: http://localhost:3000. Админка: http://localhost:3000/admin.

Первый вход: скопируйте код из `data/setup-key.txt`, введите его в админке и создайте свой пароль (минимум 12 символов). Код одноразовый и удаляется после настройки; пароль хранится в виде scrypt-хеша. В браузере используется подписанная HttpOnly SameSite=Strict сессия на 8 часов. При следующем входе нужен только выбранный пароль. Код настройки не публикуется сайтом и не включён в ZIP. Не передавайте его другим людям.

В этой рабочей папке код настройки уже подготовлен. Для проекта из ZIP выполните `npm run admin:setup`.

Production: `npm run build`, затем `npm start`.

## Как добавить свой бит

1. Админка → «Биты» → «Добавить бит».
2. Название, URL латиницей, BPM, тональность, жанр, настроение и длительность превью в секундах. Длительность можно ввести вручную; браузер пытается определить её при выборе аудио.
3. Квадратная JPG / PNG / WebP обложка (до 8 МБ).
4. Превью MP3 / WAV / OGG / M4A (до 40 МБ). Для продажи рекомендуется tagged MP3.
5. Отдельно загрузите оригинальный MP3 (до 40 МБ), WAV (до 200 МБ) и stems ZIP (до 300 МБ). Они хранятся закрыто, не в public.
6. Выберите лицензии. Для конкретного бита можно задать собственную цену и инвойс; пустые поля наследуют общие значения.
7. Выберите «Опубликован», «Черновик / скрыт» или «Продан» и сохраните.

Каталог и страница `/beats/[slug]` обновляются без изменения исходников и без повторной сборки. Кнопка «Изменить» позволяет менять данные и заменять файлы. Если новый файл не выбран, текущий остаётся. Биты скрываются статусом; физическое удаление намеренно не добавлено, чтобы не нарушать выполненные заказы.

## Лицензии и PayPal

Раздел «Лицензии и PayPal» меняет общие цены и ссылки. Предоставленный инвойс `https://www.paypal.com/invoice/p/#FRGRTPPA7A4HW4MU` установлен для Trackout за **100 USD**. Его сумма взята из вашего сообщения; приложение не проверяет сумму или статус в PayPal без API. Другие ссылки пока пустые: checkout для этих лицензий не предлагает оплату.

**Один инвойс — один заказ.** Ссылка конкретного инвойса не является многоразовой кнопкой оплаты. После создания заказа этот URL резервируется в магазине. Новый заказ с тем же инвойсом блокируется; продавец добавляет новый инвойс в общие настройки, конкретный бит или существующий заказ. Отменённый заказ тоже сохраняет историю использованного URL — не возвращайте уже оплаченный счёт в продажу. Для нескольких битов в одной корзине нужны разные инвойсы для каждой позиции.

Проверьте сумму и описание счёта в PayPal перед добавлением ссылки. Изменение цены на сайте не меняет сумму инвойса в PayPal. Состояние счёта (включая оплату вне магазина) не синхронизируется автоматически.

## Заказы и выдача файлов

Покупатель вводит Email и Artist Name, получает приватную страницу заказа и открывает инвойс в PayPal. Открытие ссылки не считается оплатой. «I have paid» переводит заказ в «Покупатель сообщил об оплате», не открывая файлы.

В админке → «Заказы» проверьте реальное поступление денег в PayPal, затем нажмите «Подтвердить оплату». После подтверждения на странице покупателя появляются разрешённые лицензией MP3 / WAV / ZIP и текстовая запись о покупке. MP3-лицензия не открывает WAV и stems, WAV-лицензия не открывает stems. Покупатель может обновить статус вручную; страница также обновляется каждые 15 секунд. Если оригиналы ещё не загружены, страница сообщает об их подготовке.

Автоматической отправки email, PayPal API / webhook и юридически окончательной лицензии нет. Покупателю нужно сохранить свою приватную ссылку заказа. Она содержит случайный секрет; без него заказ и файлы недоступны. Не публикуйте такие ссылки. Тексты прав остаются демонстрационными и требуют замены перед публичными продажами. Текстовая запись о покупке не заменяет итоговый договор лицензии.

## Данные и размещение

- `data/store.json`: биты, цены, инвойсы, заказы. Атомарная запись и файловая блокировка защищают параллельные изменения.
- `data/uploads/`: обложки, превью, закрытые оригиналы.
- `data/admin.json`: хеш пароля и секрет подписи сессии. Никогда не публикуйте эту папку.
- `data/setup-key.txt`: одноразовый код до первого входа.

Все данные сохраняются после перезапуска. Делайте резервную копию **всей папки data**. Старые файлы после замены остаются на диске; очистка неиспользуемых файлов и физическое удаление битов ещё не реализованы.

Используйте постоянный Node.js сервер/VPS с записываемым диском. Эфемерное файловое хранилище serverless-хостинга и статический export для этой версии не подходят. `STORE_DATA_DIR` задаёт абсолютный путь постоянного хранилища. На публичном HTTPS-домене настройте `APP_ORIGIN=https://ваш-домен` для защиты запросов и Secure cookie. Пример — `.env.example`. Reverse proxy должен допускать нужный размер upload (совокупно до 590 МБ). Место на диске должно быть достаточным для загружаемых WAV / ZIP. На этом компьютере свободного места мало; большие файлы могут не поместиться.

После аварийного завершения во время записи может остаться `data/store.lock`. Удаляйте этот файл только после остановки всех экземпляров сервера, затем запускайте сервер заново. Не удаляйте `store.json`, `admin.json` и uploads. В случае потери пароля восстановление выполняется владельцем сервера: после остановки сервера сохраните резервную копию, удалите только `admin.json`, выполните `npm run admin:setup` и задайте новый пароль. Это также отзывает старые сессии.

## Основные файлы

| Путь | Назначение |
| --- | --- |
| `components/admin/` | Админка, редактор и загрузка с индикатором прогресса |
| `lib/server/storage.ts` | Постоянное хранилище и атомарные изменения |
| `lib/server/auth.ts` | Настройка, пароль, сессии, same-origin и лимит входов |
| `lib/server/uploads.ts` | Проверка файлов и потоковая выдача с Range |
| `lib/server/orders.ts` | Проверка корзины, цен, лицензий и резерв инвойсов |
| `app/api/admin/` | Защищённые операции администратора |
| `app/api/orders/` | Заказы покупателя и защищённые скачивания |
| `app/api/catalog/` | Публичный каталог без оригинальных файлов |
| `lib/payments.ts` | InvoicePaymentService; сюда позже подключается PayPal API |
| `lib/beats.ts`, `lib/config.ts` | Только начальные демо-данные; после первого сохранения используется data/store.json |
| `lib/pricing.ts` | Общие цены и переопределения для каждого бита |

## Проверка

```sh
npm run lint
npm run typecheck
npm run build
```

Проверены lint, TypeScript и production build. На изолированном хранилище проверены: вход и CSRF, upload cover/preview/WAV/ZIP, публикация и скрытие, новые URL без сборки, Range аудио, закрытые оригиналы, отсутствие инвойса, запрет повторного инвойса, серверная проверка цены, reported/paid, выдача правильных файлов после ручного подтверждения. Через браузер проверены вход, загрузка обложки и аудио, сохранение нового бита и мобильная админка 390 px. Тестовые заказы и аккаунт не входят в рабочие данные или ZIP; реальная оплата PayPal не проводилась.


## Импорт YouTube
В админке есть «Импорт YouTube» со списком 452 видео канала @mapemorrisbeats на 4 октября 2026 года. Выберите нужные видео или все и нажмите «Импортировать». Повторные видео пропускаются, включая удалённые: их можно восстановить. Импорт публикует название, обложку и встроенное YouTube-превью. BPM и тональность необязательны. Оригинальные MP3/WAV/stems загружаются отдельно. Список является сохранённым снимком; будущие видео не синхронизируются автоматически. Само воспроизведение и доступность роликов зависят от YouTube.
